Buat kode kata sandi baru

Halaman khusus admin. Ketik kata sandi baru, lalu salin kodenya ke file index.html. Kata sandi tidak dikirim ke mana pun.

Kode akan muncul di sini…
  1. Buka file index.html di folder landing-vercel.
  2. Cari baris var PASSWORD_HASH = "…";
  3. Ganti isi di dalam tanda kutip dengan kode di atas, lalu simpan.
  4. Upload ulang ke Vercel. Semua guru harus memasukkan kata sandi baru.
